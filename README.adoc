== Purpose

Xseed v1.0.0 is a production-ready Ruby port of two complementary XSD documentation tools:

* **XSDVI** (Java) - XSD to interactive SVG diagram generation
* **XS3P** (XSLT) - XSD to HTML documentation generation

Xseed provides a unified Ruby gem for generating comprehensive documentation
from XML Schema Definition (XSD) files with exceptional performance and
**100% parity** with reference implementations.

== Features

* <<svg-generation,SVG diagram generation>> - Interactive, hierarchical schema
  visualizations **✅ 100% PARITY**
* <<html-documentation,HTML documentation generation>> - Comprehensive schema
  documentation with examples **✅ 100% PARITY**
* <<cli-interface,Command-line interface>> - Professional Thor-based CLI with
  verbose mode, progress indicators, and helpful error messages
* <<performance,High performance>> - Generate diagrams for large schemas in
  milliseconds (real-world: ~15ms SVG, ~260ms HTML)
* <<error-handling,Robust error handling>> - Graceful degradation with helpful
  error messages
* **21 complete features** - All P0, P1, and P2 features implemented

== Quick Start

[source,shell]
----
# Install the gem
gem install xseed

# Generate SVG diagram
xseed svg schema.xsd -o diagram.svg

# View schema information
xseed info schema.xsd

# Generate with verbose output
xseed svg schema.xsd -o diagram.svg --verbose

# Display help
xseed help svg
----

==== Generate SVG diagrams

[[svg-generation]]
===== Basic SVG generation

[source,shell]
----
# Generate SVG diagram to file
xseed svg schema.xsd -o diagram.svg

# Output to stdout (useful for piping)
xseed svg schema.xsd > diagram.svg

# Generate with verbose progress output
xseed svg schema.xsd -o diagram.svg --verbose

# Force overwrite existing file
xseed svg schema.xsd -o diagram.svg --force
----

===== SVG generation options

* `-o, --output PATH` - Output file path (default: stdout)
* `-e, --element ELEMENT_NAME` - Generate diagram for a single element
* `--all-elements` - Generate diagrams for all elements in schema
* `-d, --output-dir DIR` - Output directory for batch generation (required with --all-elements)
* `-v, --verbose` - Enable verbose output with progress indicators
* `-f, --force` - Overwrite output file without confirmation

===== Single-element mode

Xseed supports generating diagrams for individual elements instead of the entire schema. This is particularly useful for large schemas where you want to focus on specific elements or generate separate diagrams for each element.

====== Generate diagram for a single element

[source,shell]
----
# Generate diagram for a specific element
xseed svg schema.xsd -e Order -o order.svg

# With verbose output
xseed svg schema.xsd -e Customer -o customer.svg --verbose
----

====== Batch generation for all elements

Generate separate diagrams for every element in the schema:

[source,shell]
----
# Generate diagrams for all elements
xseed svg schema.xsd --all-elements -d output_directory

# With verbose progress reporting
xseed svg schema.xsd --all-elements -d diagrams --verbose
----

=== Programmatic API

==== XSD Parser

===== General

The XSD Parser is a core shared component that extracts schema components and
metadata from XML Schema Definition (XSD) files using Nokogiri with strict
validation.

The parser provides access to:

* Schema metadata (target namespace, version, element form defaults)
* Global elements, complex types, and simple types
* Groups and attribute groups
* Namespace mappings
* Documentation and annotations
* Import and include declarations

===== Basic usage

[source,ruby]
----
require "xseed"

# Parse an XSD file
parser = Xseed::Parser::XsdParser.new("schema.xsd")

# Access schema metadata
puts parser.target_namespace
puts parser.element_form_default
puts parser.schema_version

# Extract components
elements = parser.elements
types = parser.types
complex_types = parser.complex_types
simple_types = parser.simple_types
groups = parser.groups

# Get namespace mappings
namespaces = parser.namespaces

# Extract documentation
doc = parser.documentation
element_doc = parser.element_documentation("ElementName")
type_doc = parser.type_documentation("TypeName")
----

===== Error handling

The parser includes comprehensive error handling:

[source,ruby]
----
begin
  parser = Xseed::Parser::XsdParser.new("schema.xsd")
rescue Xseed::ParserError => e
  puts "Parser error: #{e.message}"
rescue Errno::ENOENT => e
  puts "File not found: #{e.message}"
end
----

===== Example output

.Example: Parsing a simple XSD
====
[source,ruby]
----
parser = Xseed::Parser::XsdParser.new("person.xsd")

puts "Target Namespace: #{parser.target_namespace}"
# => Target Namespace: http://example.com/person

puts "Elements:"
parser.elements.each do |element|
  name = element["name"]
  type = element["type"]
  puts "  - #{name} (#{type})"
end
# => Elements:
#      - person (tns:PersonType)
#      - contact (tns:ContactType)

puts "Complex Types:"
parser.complex_types.each do |type|
  puts "  - #{type['name']}"
end
# => Complex Types:
#      - PersonType
#      - ContactType
----

==== SVG Generator

===== General

The SVG generator creates visual representations of XML Schema structures with:

* Hierarchical tree layout with automatic positioning
* Clear parent-child relationships via connector lines
* Differentiated symbol types (14 distinct types)
* Color-coded visualization for different XSD components
* Embedded CSS styling
* Hover effects and tooltips with documentation
* Valid, standards-compliant SVG output

===== Architecture

The SVG generation workflow:

[source]
----
XSD File → Parser → Symbol Tree → Layout Engine → SVG Renderer → SVG Output
----

1. **Parser**: Extracts schema components with validation
2. **Symbol Factory**: Builds hierarchical symbol tree
3. **Layout Engine**: Positions symbols with collision avoidance
4. **SVG Renderer**: Generates final SVG with styles and connectors

===== Basic usage

[source,ruby]
----
require "xseed"

# Generate SVG for a schema
generator = Xseed::Svg::SvgGenerator.new("schema.xsd")
svg_content = generator.generate

# Write to file
generator.generate_file("diagram.svg")

# With error handling
begin
  generator = Xseed::Svg::SvgGenerator.new("schema.xsd")
  generator.generate_file("output.svg")
rescue ArgumentError => e
  puts "Validation error: #{e.message}"
rescue Xseed::Svg::GenerationError => e
  puts "Generation error: #{e.message}"
end
----

==== HTML Generator

===== General

The HTML generator creates comprehensive documentation from XML Schema files with:

* Schema properties table with metadata
* Component listings (elements, types, groups)
* Properties tables for each component
* Type hierarchies and substitution groups
* XML instance representation samples
* Navigable table of contents
* Responsive design with Bootstrap
* Interactive JavaScript features

===== Architecture

The HTML generation workflow:

[source]
----
XSD File → Parser → Config → HTML Generator → Renderers → HTML Output
                                    ↓
                    ┌───────────────┴───────────────┐
                    │                               │
            Navigation Renderer              Content Renderers
                    │                               │
            ┌───────┴───────┐         ┌─────────────┼─────────────┐
            │               │         │             │             │
        Sidebar TOC    Breadcrumbs  Properties  Instance    Type Hierarchy
                                     Tables      Samples     Tables
----

1. **Parser**: Extracts schema components with validation
2. **Config**: Configuration settings for generation
3. **HTML Generator**: Orchestrates rendering process
4. **Renderers**: Specialized renderers for different content types
5. **Output**: Complete HTML5 document with embedded CSS/JS

===== Basic usage

[source,ruby]
----
require "xseed"

# Basic generation
generator = Xseed::Documentation::HtmlGenerator.new("schema.xsd")
html = generator.generate
File.write("output.html", html)

# Custom configuration
config = Xseed::Documentation::Config.new
config.title = "My Schema"
config.sort_by_component = true
config.print_glossary = true

generator = Xseed::Documentation::HtmlGenerator.new("schema.xsd", config)
generator.generate_file("docs.html")
----

===== Configuration options

[cols="1,1,3"]

|String

|===

Xseed includes comprehensive error handling with helpful messages:

==== File not found

[source]
----
✗ Error: Validation error: File not found: schema.xsd

Solution: Check that the file path is correct and the file exists.
----

==== Invalid XML

[source]
----
✗ Error: Parser error: Invalid XML syntax: ...

Solution: Validate your XSD file with an XML validator.
----

==== Invalid XSD structure

[source]
----
✗ Error: Validation error: Invalid XSD file: root element must be 'schema'

Solution: Ensure the file is a valid XSD with <xs:schema> as root element.

[source]

* Provides placeholder for empty schemas

[[troubleshooting]]
== Troubleshooting

=== SVG not generating

1. **Verify XSD is valid:**
   ```
   xseed info schema.xsd
   ```

2. **Check for errors with verbose mode:**
   ```
   xseed svg schema.xsd -o output.svg --verbose
   ```

3. **Test with a simple schema first**

=== Output file not created

1. **Check directory permissions**
2. **Use --force to overwrite existing files**
3. **Verify output path is writable**

=== Performance issues

1. **Check schema complexity:**
   ```
   xseed info large-schema.xsd
   ```

2. **For very large schemas (> 200 components):**
   * Generation may take a few seconds
   * Consider breaking into smaller modules

=== Getting help

1. **View command help:**
   ```
   xseed help [command]
   ```

2. **Enable verbose output:**
   ```
   xseed svg schema.xsd -o output.svg --verbose
   ```

3. **Check GitHub issues:**
   https://github.com/metanorma/xseed/issues
